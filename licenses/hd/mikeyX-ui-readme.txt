Pokemon XD UI SVGs

These can be used as a template to make new designs or adapt UI elements for a rom hack of Pokemon XD (or anything else your imagination can dig up :P).
You can export these as PNGs at the original resolution and import them in the game using Stars' GoD-Tool (see Discord link below).
File names are the simply the names Dolphin exported the textures as. Rename them for the files you want to replace in the .fsys files.

These vector images have been done by hand by following the original images (still included) using Inkscape, a free and open-source vector image editor. https://inkscape.org/
I recommand the use of Inkscape for editing because the SVGs has some Inkscape specific elements.
Some images have been exported and then edited in Photoshop for things like Bevels, Shadows and Glows. Not everyone might have Photoshop, so I at least exported my edit to allow direct editing for those in other software.
Other assets I used are also included.

The UI for VS Mode is not included, only the main game has been done.
