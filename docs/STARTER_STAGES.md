# Starter stages and balance

Both randomizing presets use base forms from three-stage families in both games.
Colosseum keeps levels 26 and 25; XD keeps level 10. Starting experience follows
the replacement species' growth curve.

In **Advanced → Starters and gifts**, choose:

| Stage | Eligible Pokémon |
| --- | --- |
| Any stage | No evolution-stage filter |
| Base form | No earlier evolution; single-stage species require disabling the three-stage filter |
| First evolution | One evolution after a base form, such as Ivysaur |
| Final evolution | An evolved form without a later evolution, such as Venusaur |

**Three-stage families only** requires two successive evolutions in the original
generation-III data. Branch count is not stage count: Eevee has two stages,
Wurmple has three. Babies count: Pichu → Pikachu → Raichu. Later-generation
evolutions are not invented.

Similar-strength matching compares base candidates with the original starter's
family base. Colosseum's pair controls compare the two selected species' final
stats and enforce distinct families and complementary types. XD has one starter.

Manual choices bypass that slot's stage and individual power filters; exclusions
and relevant pair rules still apply. A retained starter can constrain its partner.
Impossible combinations produce an explanation instead of ignoring exclusions.

Stage filtering does not make an evolution obtainable: evolution adaptations
and stone shops handle that. Pokémon sheets read the final patched requirements.
Imported profiles retain their recorded settings, including the former power
and pair rules in older Pokémon-only profiles. Selecting the current preset
explicitly applies the new balance policy. Interface language does not affect
the draw. See [compatibility](COMPATIBILITY.md) and the [user guide](USER_GUIDE.md).
