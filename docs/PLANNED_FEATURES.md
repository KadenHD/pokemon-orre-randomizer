# Planned features

These requests are planned after v2.1.3 and are not included in that release.

## Deoxys forms in Colosseum

Add Attack, Defense and Speed Formes using XD's models, alongside Normal Forme.
Cover both standard and Shiny appearances, native assets and their HD versions.
Include the corresponding portraits, Snag List and DNA views, battle and field
models, and form-specific gameplay data where applicable. Verify the imported
animations and resource compatibility in Colosseum before release.
