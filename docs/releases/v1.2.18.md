# Pokémon Orre Randomizer v1.2.18

Colosseum's DNA analyzer and door keypad now show the randomized Shadow Pokémon.
They use shiny colors when known, and the keypad shows the same Spinda spot
pattern as the hologram when the game can determine it. The door code still
works when multiple samples show the same species.

Unown's letter or punctuation form comes from the seed and stays consistent in
both games, including battles, supported scenes and the desktop preview.

Spinda's spots follow its in-game personality value. The Pokémon sheet shows
the exact pattern when it can be determined before play. When the pattern or
color depends on the save or encounter, the sheet explains what the game will
decide.

Download the Windows setup EXE to install the app, or use the Windows ZIP to
run it as a portable app.
