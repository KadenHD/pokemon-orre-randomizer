# Pokémon Orre Randomizer v1.2.16

This release fixes an intermittent freeze after generating a Pokémon preview
in XD. The preview is calculated in the background, and the interface stays
responsive while that task finishes.

The README now shows matching Colosseum and XD screens side by side and gives
the randomized starters more time on screen in the motorcycle GIF.

Download the setup EXE to install the app for your Windows user, or extract
the Windows ZIP to run it as a portable app.
