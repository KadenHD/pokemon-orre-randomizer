# Pokémon Orre Randomizer v1.2.24

Opening the Pokémon preview now loads only encounters whose species is already
known from your settings. Their portraits, sheets and seeded shiny status appear
automatically. Randomized replacements and the full ROM plan are calculated only
after clicking **Calculate preview**. Cancellation and changes to the ROM, seed
or rules discard stale results.

Preserved species keep their original abilities, starting moves, level-up moves,
compatible TM moves, types, base stats and held items. Shiny settings and
accessible evolutions still apply. Shared species tables protect the evolution
family too. **Advanced > Allowed Pokémon > Randomize preserved Pokémon’s
properties** opts these encounters into your selected property rules; both
randomized presets leave it unchecked.

Older profiles retain their previous rules when imported. Their ROM patch bytes
were compared with the actual v1.2.23 sources in both games and both presets.

Shared explanations, English README captures and the user guide are updated.
The guide also clarifies that Poké Spot sheets show level-up moves and TMs;
their four active moves depend on the generated encounter level.

Download the **Windows setup EXE** to install the app, or the **Windows ZIP**
for a portable copy. Supply your own supported, unmodified ISO or RVZ. No ROM
or save is included.

Validation: 938 Python tests across 109 isolated modules (two Windows symlink
checks skipped), four Rust codec tests, 204 packaged UI states, read-only
comparisons on original game inputs and muted Qt views. This release does not add a new Dolphin campaign playthrough.
See [validation scope](../VALIDATION.md).
