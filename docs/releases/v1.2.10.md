# Pokémon Orre Randomizer v1.2.10

- XD's Mt. Battle prizes and Hordel's and Duking's trade rewards now match the
  shiny status shown in the preview when shininess is tied to the seed.
- These gifts keep the trainer ID assigned by the game.
- Colosseum profiles and creation reports from 1.2.9 remain importable.

Create a new randomized ROM with this version to apply the fix. See the
[story gift audit](../reverse-engineering/STORY_GIFT_SCENES.md) for the Dolphin
tests and regional checks.
