# Pokémon Orre Randomizer v1.2.8

- Pokémon previews and sheets restore missing accents where the original name
  matches the localized spelling. For example, the French interface shows
  Évoli and Salamèche.
- Evolution requirements show readable item names in English, French, German,
  Spanish, Italian and Japanese. Names use sentence casing where applicable.
- XD's Sun Shard and Moon Shard have localized names in Eevee's evolution
  requirements.
