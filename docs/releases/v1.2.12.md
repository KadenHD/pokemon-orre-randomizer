# Pokémon Orre Randomizer v1.2.12

In Pokémon XD, the Gateon Port sailor now refers to Eevee in general when
explaining evolution stones and shards to a player with a different starter.
The player can still choose and receive an item.

Generate a new ROM with the same seed and settings to apply the text fix.
See the [validation notes](../VALIDATION.md#dialogue-that-follows-a-randomized-species)
for the Dolphin replay and regional checks.
