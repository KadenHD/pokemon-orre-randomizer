# Pokémon Orre Randomizer v1.2.3

The game selection screen now uses the original transparent English logos in
high resolution. Colosseum's logo is 1280 × 543 pixels, and the full XD: Gale of
Darkness logo is 1280 × 565 pixels. The app bundles both PNGs for offline use.

[View the updated home screen](https://github.com/KadenHD/pokemon-orre-randomizer/blob/v1.2.3/docs/images/home.png)
