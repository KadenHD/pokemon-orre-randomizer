# Pokémon Orre Randomizer v1.2.1

This development tag was not published. The creation-details correction and all
changes below are included in [v1.2.2](v1.2.2.md).

## Changes since v1.2.0

- Shared Colosseum/XD labels, help, preset descriptions, control order and applied
  settings summaries now use the same wording in all six interface languages.
- XD shows the original Shadow, gift and Poké Spot rosters before calculation,
  with question marks for unknown replacements. Multilingual search is available
  before and after calculation.
- Both previews use the same background worker lifecycle, cosmetic loading cycle,
  cancel/retry states, seeded shiny legend and shared Pokémon sheets. Stale results
  are discarded after source, seed or rule changes.
- XD gains a duplicate-family warning, original-ROM comparison after report
  import, creation-stage log and safe reuse of a verified preview patch plan.
- The Impeccable design reference, sidecar and surface brief now describe the
  current interface, themes and defaults. The user and contributor documentation
  records shared behavior and the intentional native differences.

The two randomizing presets retain their existing balance and seeded 5% shiny
defaults for supported encounters. This update does not change seeded selection
rules. Colosseum's starter pair and event gifts, and XD's tutorial, trades,
Poké Spots and protected Shadow Lugia keep their own controls and explanations.

## Originals, saves and compatibility

Original ROMs and personal saves are preserved. Imported profiles retain saved
values. Start a new game to match the full preview: previously generated Pokémon
are not rerolled. XD's wild Poké Spots retain native shiny odds; its optional
Shadow shiny unlock remains enabled in both randomizing presets by default.

## Verification scope

Local validation completed 527 tests without failures (two platform skips),
456 states of the frozen Windows interface across six languages and two sizes,
and 24 visual comparisons between the two game workspaces. Dedicated regressions
cover vocabulary, search, cancellation, sheets, reports and patch-plan reuse.

Read-only previews used original Colosseum and XD images. XD's native pending
roster was checked against Europe, USA and Japan data. Its three modes produced
the same creation patches with or without preview-plan reuse; unchanged copy
produced zero patches. Original hashes remained unchanged.

The release workflow also checks Windows/Linux tests, archive integrity, packaged
startup and installation/diagnostics/uninstallation on hosted Windows. This is
an interface and workflow update; it does not claim a new full Dolphin campaign.

See [validation](https://github.com/KadenHD/pokemon-orre-randomizer/blob/v1.2.1/docs/VALIDATION.md)
and the [changelog](https://github.com/KadenHD/pokemon-orre-randomizer/blob/v1.2.1/CHANGELOG.md).
