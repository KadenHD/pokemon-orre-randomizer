# Pokémon Orre Randomizer v1.2.6

- Pokémon sheets use the original Colosseum or XD badges for Pokémon and move
  types. This includes current moves, level-up moves, and compatible TMs in all
  six interface languages.
- Shadow moves use a localized text label. Other type labels are available
  when hovering over a badge or using a screen reader.
- Move names now use sentence case. For example, `STEEL WING` appears as
  `Steel wing`.
