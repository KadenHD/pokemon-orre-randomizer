# Pokémon Orre Randomizer v1.2.17

The interface stays responsive while ROM creation and report checks finish.

fall back to the GitHub asset API. If the test suite stalls, the job prints a
thread traceback.

Download the Windows setup EXE to install the app, or use the Windows ZIP
to run it as a portable app.
